- **Task:** ENAM Holdings AI Engineer Build Challenge. Build **FINN**, a mobile-first financial investment agent.
- **Deadline:** Sun 15 Nov 2026. Submit to assessment@enam.com, subject **"IIT Delhi – AI Engineer - 2027"**.

- **Grading:** creativity, product sense, judgment, architecture. "Thin-but-working beats broad-but-broken." Bonus points for cost efficiency (cheap model for bulk work, strong model only for reasoning, caching).
- **Stack decided:** Python + FastAPI + SQLite; yfinance; NSE API (session cookies) with BSE API fallback; screener.in; PyMuPDF/pdfplumber; Gemini Flash (cheap) + a stronger model for reasoning; React + Tailwind PWA on Vercel; backend on Render/Railway; optional Telegram push.
